# StudyMate AI – SaaS Product Landing Page

A responsive, modern SaaS landing page built for **StudyMate AI**, an AI-powered study and exam preparation assistant designed to convert complex syllabus PDFs into structured 10-heading notes, memory stories, and instant mock quizzes.

## 🚀 Features Included
- **Sticky Responsive Navbar:** Smooth anchor scrolling and mobile hamburger menu.
- **Hero Section:** Product value proposition, call-to-action buttons, and an interactive SaaS workspace preview card.
- **Key Features & How It Works:** Clear 3-card grid layouts explaining product capabilities and workflow.
- **Interactive Pricing Plans:** Starter (Free) and Exam Pro plans that auto-populate the demo request form upon selection.
- **Demo Request Form with Validation:** Client-side input validation for name and email with instant confirmation feedback.

## 🛠️ Technologies Used
- **HTML5** (Semantic structure)
- **CSS3** (Custom properties, CSS Grid, Flexbox, responsive media queries)
- **Vanilla JavaScript** (DOM manipulation, mobile menu toggle, plan selection, form validation)

## 💻 How to Run Locally
1. Clone or download this repository.
2. Open the project folder in **Visual Studio Code**.
3. Open `index.html` directly in any web browser (or use the **Live Server** extension in VS Code).
